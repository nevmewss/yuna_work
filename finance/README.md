# Мої платежі — простий сервіс для таблиці доходів і витрат

Сторінка з великими кнопками для людей, яким складно користуватися телефоном.
Людина натискає **«➕ Додати запис»** і проходить 5 простих кроків:

1. **Дохід** чи **Витрата** (дві великі кнопки)
2. **Картка** — вибрати зі списку або ввести номер (+ ім'я)
3. **Призначення платежу** — вибрати зі списку або написати своє
4. **Сума і дата** (суму можна пропустити)
5. **Документ** — прикріпити файл/фото чеку або просто написати назву

Потім таблицю можна завантажити як **Excel** або **PDF**.
Колонки: № · Дата · Тип · Номер картки · Ім'я · Призначення платежу · Сума · Документ.

## Як налаштувати картки і списки
Відкрийте файл [`config.js`](config.js) і замініть приклади в `CARDS`
на справжні імена й номери карт. Там же — списки призначень для доходу і витрати.

## Як опублікувати
GitHub → Settings → Pages → Source: *Deploy from a branch* → гілка, папка `/ (root)`.
Сервіс буде доступний за адресою `https://<ваш-логін>.github.io/yuna_work/finance/`.

## Важливо знати
- Записи і прикріплені файли зберігаються **лише на тому телефоні/браузері**, де їх ввели
  (localStorage + IndexedDB). Інтернет-сервер не потрібен, але якщо очистити дані браузера — записи зникнуть.
  Тому періодично завантажуйте Excel/PDF.
- Кожен прикріплений файл завантажується окремо кнопкою «⬇️ Файл» у записі. У таблиці лише його назва.
- Синхронізації між пристроями (Google Drive тощо) поки немає — це наступний крок.

Бібліотеки (у папці `vendor/`): SheetJS `xlsx` 0.18.5 (Excel), `pdfmake` 0.2.7 (PDF, шрифт Roboto з кирилицею).
